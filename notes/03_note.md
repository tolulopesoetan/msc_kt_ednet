The knowlegde tracing notebook has been developed into an end-to-end comparison of Bayesian Knowledge Tracing (BKT), Deep Knowledge Tracing (DKT), and Self-Attentive Knowledge Tracing (SAKT) on the Riiid Answer Correctness Prediction dataset. The notebook now downloads and validates the required data, randomly selects 20,000 students, processes the interaction data in memory-efficient chunks, removes lecture records, merges question metadata, sorts each learner's interactions chronologically, and encodes the question tags as integer skill IDs. A student-level train/test split is used to ensure that the same learner does not appear in both partitions.

The notebook now prepares sequence-based data for the neural knowledge tracing models by combining skill and response information into interaction tokens, truncating learner histories to a fixed maximum length, and padding shorter sequences. A DKT model was implemented using an embedding layer and an LSTM architecture. A SAKT model was implemented using interaction embeddings, positional embeddings, multi-head self-attention, residual connections, layer normalisation, and feed-forward layers. Padded interactions are excluded from training and evaluation so that they do not influence the calculated results.

During the SAKT development, the initial attention mask was found to permit access to future response information, which produced an artificially high result. The notebook now retains this initial model as a technical diagnostic and then rebuilds SAKT using a lower-triangular causal attention mask combined with a padding mask. The causal SAKT result is used in the primary comparison with BKT and DKT. The notebook calculates AUC and accuracy for all three primary models and produces comparison tables, ROC curves, an AUC and accuracy chart, and a separate figure showing the effect of future-response access on SAKT performance.

The notebook has also been extended with several supporting experiments. These include testing different question tags and question parts as BKT skill labels, comparing sequence lengths of 100 and 200, tuning DKT and SAKT hyperparameters using a validation subset, comparing model performance across learner-history groups, testing performance on rare and common skills, and assessing probability reliability using Expected Calibration Error, Brier score, and calibration curves. Prediction arrays, training histories, tables, configuration records, and publication-quality figures are exported into organised project folders.

The main technical findings are that student-level separation is necessary to prevent learner overlap, padded sequence positions must be excluded from evaluation, and SAKT requires a correctly constructed causal mask to prevent temporal information leakage.
