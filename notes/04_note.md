Date: 16/08/2026

The knowledge tracing notebook has been strengthened beyond the initial end-to-end comparison. DKT and SAKT now use a canonical next-response formulation in which the completed skill-response history is kept separate from the skill being queried. At each prediction position, the models receive only the learner's previous interactions and the identity of the next skill; the response being predicted is excluded from the input. Padding tokens and padded targets are masked during training and evaluation. These changes ensure that the neural models are evaluated on the same prediction task and prevent same-step target leakage.

The model-selection procedure has also been revised. DKT was tuned across eight combinations of embedding dimension, LSTM units and learning rate, while SAKT was tuned across sixteen combinations of embedding dimension, attention heads, feed-forward capacity and learning rate. Hyperparameter selection uses only the learner-separated validation data. Early stopping restores the weights from the epoch with the lowest validation loss, and the selected number of epochs is then used when refitting each final neural model on the complete training partition. The final DKT and SAKT configurations are trained with three predetermined seeds, 42, 43 and 44. The AUC for each seed and the variation between seeds are retained, while the three predicted probabilities are averaged for the main evaluation. This reduces the influence of a single favourable neural-network initialisation.

The evaluation framework now distinguishes between model-specific coverage and direct like-for-like comparison. A model-specific table reports each model using all of its available predictions. A second strict common table contains only interactions for which BKT, DKT and SAKT all produced a prediction, matched by learner, interaction position, skill and actual response. Direct model-ranking conclusions are based on this common subset so that differences in sequence coverage are not mistaken for differences in predictive quality. Evaluation now includes ROC-AUC, PR-AUC, accuracy, balanced accuracy, precision, recall, F1, false-positive and false-negative rates, Brier score and log loss. Classification measures are reported at both the fixed 0.50 threshold and a model-specific threshold selected from the validation set using Youden's J statistic, without using held-out test labels for threshold selection.

Uncertainty is now assessed with 200 learner-level bootstrap replicates. Learners, rather than individual interaction rows, are resampled so that responses from the same learner remain together. Confidence intervals are produced for model AUC values, and pairwise AUC differences are calculated with the same resampled learners for both models. A performance difference is treated as supported only when the paired confidence interval excludes zero. The sequence-length comparison between 100 and 200 interactions was also rebuilt as an aligned sensitivity analysis: both versions are compared only on matching prediction targets, with the architecture and seeds held fixed, and the 200-interaction run is not used to select a model from the test results.

The stratified analysis has been made more defensible. Learner history is measured at each prediction position and divided into six groups: 1-5, 6-20, 21-50, 51-100, 101-500 and 501 or more prior interactions. Skill frequency is calculated from the training partition only, with skills in the bottom quarter labelled rare and the remaining skills labelled common. A stratum is considered suitable for interpretation only when it contains at least 500 interactions, at least 30 learners, and both outcome classes. A potential failure mode is flagged when an eligible stratum's AUC is at least 0.03 below that model's overall common-subset AUC. These cut-offs are recorded as researcher-defined screening rules rather than universal statistical standards, and the corresponding confidence interval and error profile are retained for interpretation.

An interaction-level disagreement analysis has been added to show where the three models behave differently. For BKT-DKT, BKT-SAKT and DKT-SAKT, the notebook reports class-disagreement rates, absolute probability differences, probability correlations and the proportion of disagreements won by each model. It also counts cases where one model alone is correct or alone is incorrect, summarises all eight possible three-model classification patterns, and identifies interactions where the range between the three predicted probabilities is at least 0.25. Calibration analysis remains separate and now reports Expected Calibration Error, Brier score, log loss and reliability diagrams on the strict common subset.

The notebook has also been extended to test cross-domain configurability using the Year 1 Sets, Functions and Linear Algebra module. A separate YAML configuration and item register define nine knowledge components without changing the existing EDNet evaluation cells. The 2019 assessment paper was used to develop the taxonomy, which was then frozen before mapping the 2020 paper as an unseen challenge. Both papers achieved complete mapping coverage and passed the item-register schema checks. Because real target-domain learner responses were unavailable, clearly labelled simulated sequences for 50 learners were used only to confirm that the BKT, canonical DKT and causal SAKT interfaces could execute with the new schema. The resulting AUC values are diagnostic execution checks and are not presented as evidence of target-domain predictive validity. The scorecard records the absence of eligible linear-algebra items and the absence of real learner-response data as scope boundaries rather than failed tests. All generated tables, histories, simulated interactions and configuration records continue to be saved within the project's original results folder structure.
